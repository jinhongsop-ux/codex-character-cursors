## 角色光标完整合集 V2.5.1

23套角色皮肤共用一个本地工作台，可以搜索、切换角色，查看完整状态，调整大小并应用到 Windows。

新增独立的character-cursor-personality-designer Skill，内置五套动作模板，按角色性格选择参考并逐格复刻。原固定蕾塞模板Skill保留。现有23款皮肤及工作台功能继续提供。

请下载 **character-cursors-full-v2.5.1.zip**，完整解压后运行 **一键安装.cmd**。Source code 压缩包是源码。

- 全部23套皮肤、本地工作台、基础形象和中文使用说明。
- 每套16项状态展示，映射17个Windows光标角色。
- 移动与窗口缩放保持人物居中、独立方向三角在四周；两种斜向动作分别设计。
- 16–256屏幕物理像素调节，深浅背景预览，应用时清除额外放大倍率。
- 一键安装、便携启动、完整性检查，恢复系统白色默认32像素或白色小号24像素。
- 四个Codex制作Skills及一键安装入口。

使用成品需要 Windows 10/11、Windows PowerShell 和 .NET Framework，无需Python、Node或联网。角色素材为位图，放大受原始分辨率限制；大小表示包含透明留白的整个画布。Windows重新登录或重载方案后如尺寸变化，请重新应用。
