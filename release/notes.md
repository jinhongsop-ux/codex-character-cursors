一个压缩包包含五款角色光标和完整本地工作台：蕾塞、蕾姆、deepseek酱、Pochita Mini、Zero Two（零二）。

请下载下方 **角色光标完整合集** ZIP，完整解压后运行 **一键安装.cmd**。GitHub 自动生成的 Source code 压缩包是源码，不是可直接使用的安装包。

- 同一工作台切换五款角色，预览16项贴图，应用17个Windows光标角色。
- 输入16–256屏幕物理像素，查看深浅背景、实时大小和功能热点，应用时清除额外放大倍率。
- 一键安装、便携启动、完整性检查、恢复系统默认或白色小号。
- 两个Codex制作Skills和一键安装入口，支持非Q版转Q版，再制作光标皮肤。
- 包含基础形象、中文使用说明和文件校验；不包含重复安装包、构建缓存、测试截图或内部制作记录。

**使用环境：** Windows 10/11、Windows PowerShell、.NET Framework。使用成品无需Python、Node或联网；使用Skills制作新皮肤另需相应开发工具。

大小指整个画布，包含透明留白。白色小号24×24为自定义尺寸，系统默认为32×32；恢复脚本恢复指定的系统方案，不还原用户安装前私人配置。系统重新登录或重载方案后如尺寸变化，请重新应用。
