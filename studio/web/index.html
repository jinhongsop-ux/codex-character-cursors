使用说明

角色光标

Windows 角色光标预览与安装工具。在角色目录中选择角色，查看各个光标状态，调整尺寸，并下载或应用整套光标。

在线与本地版本 在线版本用于预览和下载。
本地版本可直接将光标应用到 Windows。

02 · 光标大小

设置光标尺寸

尺寸表示整个光标画布，单位为屏幕物理像素，包含透明留白。推荐从 24–32 px 开始，也可输入 16–256 px 的整数尺寸。

03 · 光标状态

光标状态

点击任意状态，可在上方预览区域查看对应光标。具体显示哪一种状态，由 Windows 或正在使用的软件决定。

部分软件会自行绘制指针，因此可能不使用 Windows 系统光标。
04 · 使用说明

使用方法

完整解压安装包后，使用本地工作台应用光标。

在线预览与安装

  1. 在角色目录中选择角色。
  2. 点击不同状态，查看光标效果。
  3. 调整尺寸，并切换背景进行预览。
  4. 点击「下载完整合集」。
  5. 将压缩包完整解压到一个文件夹中。
  6. 双击文件夹内的「一键安装.cmd」。
  7. 在打开的本地工作台中选择角色和尺寸。
  8. 点击「应用到 Windows」。

请勿直接在压缩包内运行安装脚本。

本地使用

  1. 打开角色光标工作台。
  2. 选择角色。
  3. 点击需要查看的光标状态。
  4. 调整光标尺寸。
  5. 点击「应用到 Windows」，应用整套光标。

恢复系统光标

在本地工作台中点击「恢复系统白色默认 · 32 px」，将系统光标恢复为白色默认样式及 32 px 画布尺寸。

也可以选择「系统白色小号 · 24 px」，切换为 24 px 的白色光标。

无需打开工作台时，可运行安装包中的「一键恢复系统默认.cmd」或「一键恢复系统白色小号.cmd」。

恢复功能不会找回安装前的自定义光标方案。

运行要求

本地版本适用于 Windows 10 / 11，需要系统具备 Windows PowerShell 和 .NET Framework。

使用成品无需安装 Python 或 Node，也无需联网。

角色更新

新增角色会加入角色目录，现有操作流程保持一致。请下载最新完整合集，以获取更新后的角色素材与功能。

注意事项

  • 光标尺寸表示整个画布尺寸，包含透明区域。不同角色、姿势的实际可见大小可能不同。
  • 预览按屏幕物理像素换算。浏览器缩放或窗口移至不同显示器后，预览尺寸会重新计算。
  • 部分软件会自行绘制鼠标指针，可能不会使用 Windows 系统光标。
  • 角色素材为位图，过度放大不会增加细节，可能降低清晰度。
  • 重新登录、切换显示设置或重新加载系统光标方案后，如果尺寸发生变化，可打开本地工作台再次应用。
  • 恢复功能会切换为指定的白色系统光标样式和尺寸，不会找回此前使用的第三方光标方案。

部分角色提供早期独立包下载，其素材和功能可能与最新版本不同。使用最新角色素材和完整功能，请下载完整合集。
