03 · COMPLETE CURSOR SET

这一套的所有状态，都在这里。

不是只换普通箭头。选择、输入、等待、移动、缩放等主要 Windows 状态完整保留；点击任意状态即可放大预览。

部分软件会自行绘制指针，因此可能不使用 Windows 系统光标。
