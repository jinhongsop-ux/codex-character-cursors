# 已确认的16贴图规范

本规范来自用户确认的多组样本。适用于此用户的角色光标设计；用户的新指示或提供的成品图优先。固定功能符号与布局，人物动作和表情随角色性格变化，不复制样本中其他角色的身份。

## 数量与布局

16个源贴图位置＝15个标准光标状态＋Extra；不要求16个独立姿势，Extra默认复用Normal。完整Windows包有17个系统角色：上述15个，加Pin和Person；后两项可复用Extra。不要把源贴图数与系统角色数混淆。

4×4预览顺序：
- 第1行：Normal、Help、Working、Busy。
- 第2行：Precision、Text、Handwriting、Unavailable。
- 第3行：Move、Horizontal、Diagonal ↗↙、Alternate。
- 第4行：Vertical、Diagonal ↖↘、Link、Extra。

## 构图必须满足

人物负责表演，符号说明用途。Move/Horizontal/Vertical/两种Diagonal的三角是有描边的独立小图形，颜色与主题协调，不能用连线双向箭头替换。人物位于箭头围成的中心区域，箭头不盖住脸、身体、发梢或服装。这里的居中指视觉上在符号之间，不是机械对齐像素中心。

两种斜向的方向和位置不可交换。Horizontal左右、Vertical上下、Move四向应在不看标签时也能辨认。保持完整人物与符号，不能为了放大而裁掉箭头。

动作与表情允许变化，不把功能强制变成道具。只有新角色创作/明确重绘时采用这些动作建议；成品图保色裁切时保留其已有动作、表情和符号，不为符合建议而重画。

## 热点与验收

单三角状态Arrow/UpArrow/Hand的热点用实际三角尖端，不用人物中心或不存在的手指尖。Help/Working/Busy按素材中的明确指向点或符号交互点确定，保留已有可靠热点。Crosshair用准星中心，IBeam用文本定位点，NWPen用笔尖。调整大小和Move用方向符号组中心作为操作点，不能一律把某个外侧三角尖端设为热点；在实际窗口边缘/角落验证定位。

生成或拆分后逐项对照16格：方向正确、人物在箭头之间、符号独立清晰、没有遮挡、两个Diagonal可区分、Extra复用准确。结合浅/深背景边缘和实际CUR热点检查；只验证文件能加载不足以证明构图符合样本。

## 新创作与重设计的动作辨识度

当用户要求更鲜明的状态变化时，先隐藏功能符号，把人物单独放到64像素的实际画布中比较。不同帧编号、不同文件哈希、换眼睛或轻微摆手，不足以证明动作有区别。用站立、前倾、蹲坐、阅读、书写、拒绝手势、侧蜷、横躺、收腿思考等不同轮廓表现状态，再加入角色自己的习惯、道具和情绪。以用户认可的蕾塞状态变化为辨识度参考，保留目标角色身份。

重点检查：Text与Handwriting能看出不同活动；Working与Busy能看出不同等待情绪；No有明确拒绝姿势；Vertical是低矮姿态，不能仅把普通站姿的眼睛闭上；两种Diagonal的身体姿势也有区别。Normal/Extra以及批准复用的Pin/Person可以相同，其余状态不应大面积复用普通站姿。

生成的4×4图可能没有严格等分对齐。裁切前检查真实轮廓与行列间隙，必要时用连通区域和透明蒙版隔离完整人物，不能把邻格脚、发梢或道具一起裁进来。检查衣摆、腿脚是否在生成阶段就被截断；缺失部位要重新生成该姿势，不能靠缩小画布掩盖。此节只适用于新创作或用户授权的重设计，成品保色裁切仍保留原图。
