# 固定16格动作与系统映射

按紫发模板从左到右、从上到下匹配。动作不得用状态语义自由改写。左右描述采用画面坐标；具体角度、手指触点和遮挡以对应模板格为准。

|格|文件名|状态 / 角色|姿势|表情与检查点|符号|
|---|---|---|---|---|---|
|01|01_normal_select.png|普通选择 / Arrow|侧身前倾，头略歪，双手靠拢放在膝前，双腿站立。|半眯眼、张嘴微笑；保留头、肩、髋的不同倾角。|左上三角|
|02|02_help_select.png|帮助选择 / Help|头和上身一起侧倾，双手背后，站姿。|抬眼疑问、小圆嘴；不能改成摸脸。|左上问号|
|03|03_working_in_background.png|后台工作 / AppStarting|正面紧凑站立，双手在身体前方并拢。|半睁眼、低能量等待。|左上环形加载|
|04|04_busy.png|忙碌等待 / Wait|正面站立，双臂自然下垂，双腿靠近。|平静疲倦；区别于双手并拢的第3格。|左上沙漏|
|05|05_precision_select.png|精确选择 / Crosshair|一手托腮，另一臂横在胸前支撑，站立。|认真思考、半眯眼。|左上十字|
|06|06_text_select.png|文字输入 / IBeam|向画面左侧的侧坐，腿伸向前，双手操作横放在腿前的键盘。|低头专注；不要默认替换成高屏笔记本或书。|左上I形|
|07|07_handwriting.png|手写 / NWPen|站立，双手叉腰，抬下巴、头后仰。|视线向上，自信微笑；不是平视、也不是实际写字。|左上笔尖|
|08|08_unavailable.png|不可用 / No|正面垂手站立，肩膀略松。|眉眼压低，眼部有暗影，冷淡不悦。|左上禁止|
|09|09_move.png|移动 / SizeAll|正面盘腿坐，双手分别托住脸颊。|开心张嘴；保留盘腿、托脸触点。|人物周围上、下、左、右四枚独立朝外三角|
|10|10_horizontal_resize.png|水平调整 / SizeWE|站立，双手背后，收肩，身体轻微倾斜。|略害羞，视线和歪头按模板。|人物左右各一枚独立朝外三角|
|11|11_diagonal_resize_1.png|斜向调整 ↗↙ / SizeNESW|侧坐，身体侧背朝向观者，回头歪头看，手撑在身旁。|安静微笑；保留回头而非正面坐姿。|右上与左下独立朝外三角|
|12|12_alternate_select.png|候选选择 / UpArrow|站立，一手贴脸，另一手在腰侧。|单眼眨眼、轻笑。|左上三角|
|13|13_vertical_resize.png|垂直调整 / SizeNS|横向趴卧，头靠近画面左侧，双臂托在脸下，完整脚伸向右侧。|半睁眼慵懒；不是闭眼蜷睡。|人物上、下各一枚独立朝外三角|
|14|14_diagonal_resize_2.png|斜向调整 ↖↘ / SizeNWSE|斜向坐，前方双腿交叠，一手靠膝，另一手在身后撑地。|半眯眼轻笑；区别于第11格侧坐回头。|左上与右下独立朝外三角|
|15|15_link_select.png|链接选择 / Hand|站立，一手向画面左侧伸出，掌心朝上作邀请，另一手叉腰。|张嘴开心；不是抬手竖掌挥手。|左上三角|
|16|16_extra.png|额外状态 / Extra|复用第1格侧身前倾、双手靠拢膝前。|与普通选择同一表情。|左上三角|

16格展示对应15个不同的传统系统角色，Extra为备用Arrow。完整Windows映射是上述15角色加Pin和Person，共17个，Pin/Person默认复用Extra。第12格UpArrow，第15格Hand，第16格Extra；不能交换或以Person取代Extra。

窗口调整的三角彼此不相连，人物置于两枚或四枚符号之间。保持头身比例一致，但趴卧、站立、盘坐的可见高度自然不同，不为统一高度将人物拉伸。
