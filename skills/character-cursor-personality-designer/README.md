# Character Cursor Personality Designer V1.2

先调查角色性格，再选择适合的16状态动作模板，保留新角色身份逐格复刻。

内置蕾塞、蝴蝶忍、炼狱杏寿郎、甘露寺密璃和灶门炭治郎五套参考。每个新IP联网确认性格与版本，简短说明模板选择理由，然后核对姿势、表情、头颈肩衔接、服装和透明边缘。

调用 `$character-cursor-personality-designer`；需要完整Windows皮肤时继续使用 character-cursor-pack。旧 character-cursor-state-designer 仍保留，适用于指定蕾塞模板。
