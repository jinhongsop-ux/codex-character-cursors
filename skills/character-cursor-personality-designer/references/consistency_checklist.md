# 逐格验收

## 身份
- 原角色发色、刘海方向、发辫数量及位置不漂移；眼色和特殊瞳孔保留。
- 服装、领口、袖长、领带、裤裙、袜鞋和标志配饰按新角色，不照搬紫发角色。
- 转2D允许简化实物细节，但不能承诺与3D照片像素RGB一致。

## 动作与表情
- 全部模板逐格检查头颈肩衔接、胸背方向、关节、支撑手、遮挡与重心。
- 下列具体动作仅适用于蕾塞模板；其余按所选参考图核对。
- 每格与对应参考并排检查头倾角、身体朝向、视线、嘴形、肩髋关系。
- 检查双手接触点、掌心朝向、支撑手、交叠腿、脚尖、遮挡及重心。
- 01前倾歪头、02双手背后、05托腮；06侧坐键盘不换高屏电脑。
- 07叉腰仰头向上看，10收肩双手背后，11侧坐回头歪头。
- 13趴卧半睁眼；14腿交叠与撑地手；15掌心朝上邀请而非挥手。
- 12候选、15链接、16额外状态的顺序正确，Extra复用Arrow。
- 仅服装不同造成的轮廓差异不判为动作错误。

## 风格、符号与输出
- 头身比例、深色描边厚度、明暗强度统一；无额外浅金/白色贴纸外边、发光、外投影。
- 允许符号填色取新角色配色；尺寸、角度、位置和人物间距对齐参考。
- 移动与缩放三角独立朝外，不连接成双头箭头，不遮脸或配饰。
- 肢体、发尾和符号完整，边界透明留白，不按固定等分线截肢体。
- 在不透明黑、灰、白和棋盘格合成背景检查真实边缘，不把alpha=0的隐藏RGB当残边。
- 24/32/64px检查清晰度与动作；所有格文件、角色映射和预览顺序一致。
